libwebp — WebP decoder (WebAssembly build)

Shipped in this app as assets/local-analyzer/webp_dec.wasm, the unmodified decoder of the npm package
@jsquash/webp 1.5.0 (SHA-256 30fb52fa2a80166d25ba7debf902218904ba1f05ccce9f959f722beff9e2f344), with that package's
JavaScript loader bundled into analyzer.mjs. Used, on the device only, to decode drawings a publisher serves as WebP.
Nothing is downloaded at run time.

@jsquash/webp (https://github.com/jamsinclair/jSquash) is licensed under the Apache License, Version 2.0; it packages
the codec built by the Squoosh project (https://github.com/GoogleChromeLabs/squoosh, Apache License 2.0).
