# AI second look, live (EXTERIOR-COMPLETE E12, research)

The analyzer's contract for asking a model about something it cannot settle has existed since 005Y-N4
(`packages/source-vision/src/second-look.ts`): the deterministic reader names two or three readings, the model's answer
is only `AI_SUGGESTED`, it becomes usable (`CV_AI_VALIDATED`) only where an independent deterministic check agrees, and
nothing leaves the machine without the owner's consent. It had never run live — no key, no consent.

In a Claude Code session the Anthropic host is authenticated by the session itself, so a key cannot be stored for it.
This directory adds a second transport for the same contract: Claude Code's headless mode (`claude -p`), the image as a
base64 block, the answer as structured output against a JSON Schema, tools off, in an empty working directory, on the
owner's Claude Code budget. Production is unchanged in behaviour: `anthropicVisionReasoner` (SDK + `ANTHROPIC_API_KEY`)
and the null provider; nothing under `packages/` imports this directory.

```
npx vite-node research/ai-assist/run-questions.ts -- <questions.json> <out-dir> [models] [repeats]
```

`questions.json` and the crops it names live outside the worktree (publishers' drawings are never committed). The
records written here (`results-e12.json`) hold texts, rectangles, hashes, costs and latencies — no pixels.

## E12 result (7 questions, 3 repeats, DEV houses — not a blind test)

| model | correct | wrong, chosen | validated (independent check) | validated wrong | cost | mean latency |
| --- | --- | --- | --- | --- | --- | --- |
| claude-haiku-5-5 | 20 / 21 | 1 | 15 | 0 | $0.014 | 4.7 s |
| claude-opus-5-5 | 21 / 21 | 0 | 15 | 0 | $0.47 | 6.8 s |

The analyzer alone was right on 1 of the 7 questions. Haiku's one wrong answer (a terrace read as a bay) was on a
question with no independent check, so it would have stayed a question to the user. Reference answers were read from
the sources by the developer after the cases were known: this measures whether the contract works on real failures, not
how often a model is right on unseen houses. Before anything here reaches the product: a blind question set (H2 stays
sealed until the campaign's contract opens it), the hypotheses generated by the reader rather than written by hand, and
a consent and budget switch in the app.
