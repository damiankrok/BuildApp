## 2. Supply-chain notes

- The DeepLSD checkpoints' only working source today is an unofficial mirror. Any future use would need the official
  file (or the authors' confirmation of these hashes) before the hashes could be trusted beyond "a mirror says so".
- DeepLSD's published install builds four C++ projects (pytlsd, GC-RANSAC, Progressive-X, line_refinement) plus
  Ceres/Eigen/OpenCV/glog/gflags; two vendored pybind11 copies (2.6.2, 2.8.1) no longer compile against CPython 3.11
  (glue replaced with pybind11 v2.13.6 for pytlsd; ELSED driven through a C++ CLI instead).
- All three Python stacks load pickled checkpoints; `weights_only=True` with an explicit allow-list was sufficient for
  all three, so no arbitrary unpickling was needed.
