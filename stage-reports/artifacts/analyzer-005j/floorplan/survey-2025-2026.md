# 005J: open-source floor-plan recognition survey, 2025–2026

**Read on:** 2026-10-06.
**Scope:** BuildPlan analyzer (TypeScript in nodejs-mobile, offline, commercial).
**Machine-readable form:** `survey-2025-2026.json` (40 records; 23 of them new in 2025–2026).
**Algorithm reuse:** `../reuse-map.md`.

## Method and limits

**Discovery**
- Hugging Face API:
  - models: 11 queries returned 292 unique ids, sorted by `lastModified`;
  - datasets: 8 queries returned 156 ids.
- arXiv export API.
- Web search.

**Verification**
- I verified every candidate against the actual artefact:
  - shallow, blob-limited `git clone` into `/home/user/work005j/upstream/<name>`;
  - `git ls-remote` or a `tree:0` fetch for the commit SHA and date;
  - `raw.githubusercontent.com` at the pinned SHA for LICENSE files, each hashed with SHA-256;
  - the HF API for revisions and LFS SHA-256 values. These are server-reported. I did not recompute them, because I downloaded no checkpoint.
- **Accidental checkpoint download.** The clone proxy ignored `--filter=blob:limit`.
  - As a result, the shallow CubiCasa5k clone pulled `model_1427.pth` (69.7 MB) into its pack.
  - It was never loaded, and I deleted the pack.
  - I also removed my duplicate ResPlan clone. The sibling clone `upstream/resplan` is at the same SHA `e2b78fe`.
- I read five safetensors headers with HTTP range requests: Yytsi, Voix7, joshlyman, Patnev71 and phungpx. That gives tensor names and parameter counts without downloading the weights.

**Not used:** no training. Nothing ran on publisher drawings.

**Network limits**
- github.com HTML and api.github.com return 403 from this container.
- 4TU.ResearchData showed a maintenance page, so I could not read MSD's licence there.

**Licence questions kept separate.** The five licence questions stay separate in every record: CODE, WEIGHT, TRAINING_DATA, PRETRAINED_BACKBONE and RUNTIME.

## Headline

1. **Still no `ADOPT_PRODUCTION`.** No 2025–2026 floor-plan model has commercially usable code, weights and training data together. Every new raster wall model with released weights is trained on CubiCasa5K, which is CC BY-NC 4.0 in its repository and CC BY-NC-SA 4.0 on Zenodo.
2. **The "SegFormer" route is NC even below the weights.**
   - `segmentation_models_pytorch`'s `mix_transformer.py` carries the NVIDIA Source Code License header (non-commercial). This holds even though smp itself is MIT.
   - `nvidia/mit-*` weights point to the same licence.
   - Affected models: MitUNet, `JessiP23/cubicasa-segformer-v2`, `Patnev71/segformer-b0-*`, the SegFormer-b2 in the Avito study, and `mjlading/walls_mitunet_b4_1536`.
   - Only Hugging Face transformers' SegFormer port carries an Apache-2.0 header, and only with non-NVIDIA pretraining. Whether that port is free of NVIDIA licence obligations is a question for counsel; the sibling `mitunet.md` reaches the same caution. ImageNet's own terms of access are a residual question for *any* ImageNet-pretrained encoder.
3. **Permissive tags on HF do not survive a check of the training data.**
   - `Yytsi/floorplan-to-3d-walls` (MIT tag): trained on CubiCasa5K.
   - `joshlyman/rtdetrv2-floorplancad-doors` (Apache tag): trained on FloorPlanCAD, which is NC.
   - `GreenMap/yolo11x-blueprint-wall-detector` (Apache tag): an Ultralytics model, so AGPL.
   - `Voix7/rtdetrv2-floorplan-v2` (Apache tag): "unknown dataset".
   - `mudasir13cs/qwen25-vl-3b-*` (Apache tag): the base model is under the qwen-research licence and the data is CubiCasa.
   - `Voxel51/FloorPlanCAD` is tagged `cc-by-sa-4.0`, but its own card body says CC BY-NC 4.0.
4. **ResPlan's data licence is now in conflict.**
   - CC BY 4.0: LICENSE at `e2b78fe` (sha256 `8193a93c…bf499`), the README and paper v2.
   - CC BY-NC-SA 4.0: `croissant.json` (sha256 `a915ed5f…7c84`) and the live Kaggle `licenseName`.
   - It cannot be a training corpus until the authors resolve this in writing. The listing provenance also needs counsel.
5. **The most valuable 2026 item is algorithmic, not a model.**
   - The paper is fpvec-lab (arXiv 2608.25608, 2026-08-26). It gives exact definitions of:
     - a tolerance-based wall F1;
     - an edit-cost metric;
     - an ink gate;
     - a heatmap graph readout;
     - a deterministic base+donor fusion rule.
   - The repository is a README only: 2 commits, no LICENSE, no code. The method can only be reimplemented from the paper.
6. **Domain-gap evidence (new).** The Avito comparative study (2026-08) used RF-DETR-Seg, YOLO11-seg, Mask R-CNN and SegFormer, trained on ResPlan + CubiCasa.
   - Validation segm mAP50 was 0.83–0.91.
   - On real photographed plans, AP50 fell to 0.05–0.28.
   - Expect the same cliff for any CubiCasa- or ResPlan-trained model on Polish catalogue sheets.

## E. Licence traps recorded for the coordinator

- **NVIDIA licence inside smp.** Any `smp` model with `encoder_name="mit_b*"` runs NVIDIA-NC *code*, not only NVIDIA-NC weights.
- **Model-card tags are not grants.** I checked the new HF floor-plan models that carry a permissive tag (MIT or Apache).
  - Six are contradicted by their own stated data or framework: Yytsi, GreenMap, joshlyman, avito, sankhya007 and mudasir13cs.
  - The others disclose no training data at all: Voix7, TallManager267, huanthuytnhh, SathvikVadavatha and Silly98.
- **ResPlan contradicts itself:** a CC BY 4.0 LICENSE file against a CC BY-NC-SA 4.0 `croissant.json`.
- **Voxel51/FloorPlanCAD:** `cc-by-sa-4.0` tag against CC BY-NC 4.0 in its card body.
- **Qwen2.5-VL-3B** (the base of the floor-plan GRPO LoRAs) is under the `qwen-research` licence.
- **CAGE:** "MIT" with Commons Clause.
- **HEAT:** a GPL wrapper inside a non-commercial grant.

## G. Limitations

**Not reachable or not verified**
- GitHub release pages and the GitHub API were not reachable. Release assets were judged from tags, LFS pointers and READMEs.
- MSD's 4TU licence and WAFFLE's licence were not verified.

**Not found**
- No code was located for FloorplanVLM, SALI-FP, FGSSNet or FRI-Net. They may exist behind blocked pages.

**Not measured or not checked**
- Phone runtime was not measured for any architecture. The only measured phone-compatible route is still 005G's onnxruntime-web WASM, with a 4 MB model.
- The HF search was keyword-based (floorplan, floor plan, blueprint, wall segmentation, cubicasa, resplan, room segmentation). Models without those words in their id were not seen.
